# ⚡ Yugesh Pandey - Modern Cyber-Dark Portfolio

A modern, high-performance developer portfolio featuring cyber-dark aesthetics, glassmorphism, interactive particle canvas, smooth animated number counters, and a fully functional AJAX PHP contact form with Gmail SMTP.

## 🛠️ Key Features
- **Cyber Dark & Glassmorphism Design:** Deep cyber-slate background, neon cyan & purple ambient radial glows, and backdrop-filter glass cards.
- **Interactive Particle Constellation Canvas:** Vanilla HTML5 Canvas particle network that responds to cursor movements.
- **Animated Number Counters:** Smooth cubic ease-out count-up animation with IntersectionObserver trigger (Live Projects, Happy Clients, Experience, Quality).
- **Working Contact Form:** Asynchronous AJAX form connected to PHPMailer with Google SMTP integration.
- **Custom Cyber Cursor:** Custom glowing pointer and lagging magnetic follower.
- **Fully Responsive:** Pixel-perfect layout across Ultra-wide, Desktop, Tablet, and Mobile screens.

## ⚙️ Setup & Local Installation
1. Clone the repository into your local server (e.g. `c:/xampp/htdocs/`):
   ```bash
   git clone https://github.com/yugeshpandey22/portfolie.git
   ```
2. Configure SMTP Credentials:
   - Copy `config.example.php` to `config.php`:
     ```bash
     cp config.example.php config.php
     ```
   - Add your Gmail address and 16-character Google App Password in `config.php`.
3. Start Apache in XAMPP and open in browser:
   ```
   http://localhost/portfolio/
   ```
